## Sign-off
The following components are validated and treated as locked for pre-engine
readiness:

- `qry_Settings_System` (global scalar settings)
- `qry_Static_Season_Config` (season-scoped configuration contract)
- All `Summary_New__*` queries (single-season, deterministic, empty-folder safe)

## Key contracts confirmed
- Season scoping uses **SeasonKey** (canonical scope key).
- **SeasonYear** is a season attribute for reporting and must not be used for
  joins/scoping.
- Exactly one season must be marked `SeasonStatus="Active"`; queries error on 0
  or >1.
- Summary layer is strictly single-season; cross-season needs are handled by
  engines or reporting queries.
